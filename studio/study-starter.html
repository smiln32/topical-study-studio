Study starter

Fill in the blanks. The starter writes the pages.

Name the study, add one session for each passage, and the starter lays out a page per session with the content types the engine prints today: read the passage, observe, words to look up, interpret, apply. Every blank you leave is filled with wording that names the passage, so no two sessions repeat a prompt. Check it, preview it, and download the finished HTML to print or the JSON to edit by hand or in the Studio.

Sessions

One per passage, in the order they are taught. The suggested wording changes when you type the passage; edit any of it.

    Check and download

    The same validator that checks the command-line factory checks this study. Preview and the finished HTML need the local generator running (python study_studio.py); the JSON download works anywhere.

    The starter quotes only the passage text you paste, and the check counts those verses against the limit of 500 in one work. Quoted text needs the publisher's notice, and you are responsible for checking the text and the publisher's other conditions at lockman.org. A study about mental health, trauma, grief, addiction or crisis is reviewed by a qualified professional before it is published or sold.
